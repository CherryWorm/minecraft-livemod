Living Mod

A private Minecraft server whose mod is written by an AI while we play.

What this is

The world starts as plain Minecraft with nothing added. The first time you join, an AI agent (Claude) talks with you in private about what you'd like from a mod. It then chooses one direction for everyone and keeps the details a surprise.

From there it keeps building: ores and plants in land you haven't reached, machines, creatures you can talk to, recipes you have to work out. Each new thing is tested automatically on a separate copy of the world, then appears in the running game. There are no patch notes. You find out by finding it.

How it grows

Early on you still mine and build by hand, with more to explore and figure out. Later comes limited automation and stronger gear, earned through the materials you've worked up to. The endgame can get as big as the agent likes.

You can steer it by talking in chat, but it has the final say. It's never finished, and it leaves what you already have alone unless there's a good reason not to.

Once the world has a theme, this page shows how it's coming along: what's out, what's being built and what's next. It's spoiler-free unless you choose otherwise.

Before you install

  • What you say goes to AI services. Your chat, your private interview answers and whatever you say to creatures are sent to Langdock's and Anthropic's AI services so the agent can respond.
  • Creatures gossip. They can repeat what you tell them to other players.
  • Your ideas can reach web searches. They can shape what the agent looks up online. A check keeps player names and long phrases from private answers out of those searches, but it can't catch a paraphrase.
  • AI-written code runs on your PC. The download includes a companion mod that loads small modules the agent writes. They're signed and checked, and they aren't allowed to use files, the network or your login, but Java has no true sandbox, so this reduces the risk rather than removing it. Typing /companion off in the game turns them off on your machine at any time.

Only install it if you're fine with all of that.

How to join

  1. Install Prism Launcher and add your Microsoft account. You need to own Minecraft: Java Edition.
  2. Download the instance. It comes with JEI, JourneyMap, Inventory Essentials, Mod Menu, FerriteCore and Patchouli by Vazkii, which we ported to this Minecraft (CC BY-NC-SA 3.0).
    Download LivingMod.zip
  3. In Prism, choose Add Instance, then Import, and pick the zip. After this it keeps itself up to date each time you start the game.
  4. Launch it. The first launch takes a few minutes. If Prism asks about Java, let it fetch the version it suggests.
  5. Open Multiplayer. Living Mod is already in the list, at {{env "GAME_ADDRESS"}}.
  6. When the game asks, enter the same password you used for this page. You only need to do this once.
  7. If something's broken, type /bug, a space, then what went wrong. An agent looks into it straight away, tells you what it finds, and fixes what it can ahead of everything else.
  8. The agent will ask you something in chat. Answer it privately by typing /dm, a space, then your message. If you leave partway through, it picks up where you stopped when you come back. Afterwards, /dm still reaches it, /plan shows what's being built, without spoilers, and /board shows or hides a sidebar with the same news.

Before the game starts

Until the first new things arrive, the world is small and safe: a glowing wall surrounds spawn, there are no monsters and no hunger, and nothing can be broken. When they arrive, the wall comes down, you can break things, monsters and hunger come back, and a new day starts. That's when the game really begins.

A short freeze when new things arrive is normal, because the game is loading them. This is an experiment, so expect the odd bug.
